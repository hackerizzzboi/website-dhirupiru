Computer Operator Syllabus

Overview of written, practical and interview components for Loksewa Computer Operator Level 5.

Exam Structure

Stage Paper / Component Marks Type Time
Written Paper I: GK & Public Management + Job-based MCQs 100 Objective (MCQ) ~45 min
Paper II: Job-based Knowledge 100 Short & Long Answer ~2–3 hrs
Practical Typing, MS Office, Email / Internet, File tasks 50 Hands-on ~45 min
Interview Personality, practical work understanding 30 Oral -

Key Course Units

  • Computer fundamentals, number system, hardware & software
  • Operating system, file & disk management, utilities
  • Word processing (Nepali & English typing integration)
  • Spreadsheet (functions, charts, basic analysis)
  • Presentation (official slide preparation)
  • Database & basic SQL (simple queries)
  • Internet, email, web basics, e-governance
  • Networking & security fundamentals
  • Basic web design (HTML/CSS)
  • General Knowledge & Public Management
  • Office procedures and record management
  • Typing: English & Devanagari speed and accuracy
